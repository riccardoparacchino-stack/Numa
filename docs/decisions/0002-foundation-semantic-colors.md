# ADR 0002: Initial Foundation Semantic Colors

- **Date:** 2026-10-31
- **Status:** Superseded by [ADR 0006](0006-foundation-color-scopes-and-responsive-containers.md)

This decision records the initial light semantic color architecture: source-only
DTCG aliases, context and interactive collections, neutral surface hierarchy,
interaction states, focus contrast, and the absence of generated outputs.

The role names and state coverage were subsequently simplified. The current
token vocabulary, reduced state set, accent and status roles, and responsive
container-query approach are defined in
[ADR 0006](0006-foundation-color-scopes-and-responsive-containers.md) and
[Foundation Semantic Colors](../foundation/semantic-colors.md).

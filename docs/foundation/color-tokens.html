01 · Semantic colors

Use these tokens for product UI. Each name communicates purpose and resolves to an existing primitive. Context describes neutral surroundings; accent is non-interactive; interactive roles describe control feedback.

Rules of use

Keep meaning stable while allowing primitive assignments to evolve. These rules describe the current light-theme token contract.

  • Choose semantic first

    Application and reusable component styles should use a semantic role. Do not select a raw shade such as indigo-600 just because it looks right.

  • Use primitives with intent

    Primitive tokens belong in Foundation mappings, token tooling, and exceptional UI that has no semantic role. Record the gap; do not silently create a component-specific alias.

  • Keep values tokenized

    Do not hardcode hex, RGB, or opacity values in product UI. Semantic colors must alias primitives. Ghost feedback uses one color alias and percentage aliases for its states.

  • Keep names purpose-based

    Do not add roles named after components (button, input, card, or link) or typography (title, body, or label). Choose roles by environmental or interactive purpose.

  • Apply state precedence

    Disabled suppresses hover and active feedback. Focus remains visible when a disabled control can receive focus. Add persistent selected roles only when a supported component needs them.

  • Preserve focus contrast

    Use the light-surface focus outline on neutral surfaces. Enabled action surfaces use the two-color focus ring: light inside and dark outside.

  • Check contrast in context

    Target at least 4.5:1 for normal text and 3:1 for non-text focus indicators. Validate the composed result, including overlays, not just the uncomposited token value.

  • Do not infer a dark theme

    Only light mappings exist today. Keep semantic roles theme-neutral, but do not assume dark aliases or automatic theme switching are implemented.

State order: disabled takes precedence over hover and active; focus composes as an outline without changing the surface fill.

02 · Primitive palette

Primitives are the source values used by semantic aliases. They describe color ramps, not product meaning. Avoid using them directly in component styles.

# Foundation

Foundation documentation describes the repository's shared design definitions
and their consumers.

## Documents

- [Typography](typography.md) — Foundation typography token values, Text
  integration, and known platform limits.
- [Architecture decisions](../decisions/0001-foundation-text-typography.md) —
  rationale for the initial typography collection and Text integration.

## Current scope

The repository contains primitive color/numeric/percentage data and a
typography-specific Foundation collection. React Web components consume these
shared values where implemented. React Native token outputs and component
support remain out of scope and are not claimed.
